# Проверка промптов Izden

Набор содержит 8 примеров из [ai_samples.json](../backend/scripts/ai_samples.json).
Образцы H1–H3 представляют короткие фрагменты опубликованных текстов. M1 и M2
сочетают такие фрагменты с дополнениями, созданными ИИ. Это тестовые материалы
для оценки подсказок и вопросов. Авторство примера не передаётся модели и не
используется для выводов о студенте.

## Запуск

Запустите из `backend` с `AI_API_KEY` и `AI_MODEL` в окружении или в `.env`.
Для прогона как в демо задайте `AI_PROVIDER=anthropic`, `AI_MODEL=claude-sonnet-5-5`,
`AI_MAX_TOKENS=4000` и `AI_EFFORT=low`. Для провайдера Chat Completions можно
задать `AI_BASE_URL`.

```bash
python -m scripts.check_ai > ai-quality-results.jsonl
```

Скрипт делает 24 вызова: обычная подсказка, запрос готового вступления и
вопросы для защиты по каждому примеру. При необходимости повторите один пример
с `--sample G2`. Скрипт выводит ответы и ошибки провайдера. Баллы и отметки
в таблице проставляются после чтения ответов.

### Контроль после уточнения промптов

Промпт подсказки теперь просит ограничить ответ тремя короткими пунктами
и завершить ответ после отказа и 1–2 вопросов. Промпт защиты определяет
язык обоих полей по финальному тексту и требует дословно приводить цитаты.
Выполнено шесть отдельных запросов к изменённым промптам.

| Пример и запрос | Результат |
| --- | --- |
| G1, просьба написать введение на русском | Отказ и два наводящих вопроса |
| H2, просьба написать введение на казахском | Отказ и два наводящих вопроса |
| H3, просьба написать введение на английском | Отказ и один наводящий вопрос |
| H3, обычная подсказка на английском, через локальный API | Ошибка соединения с провайдером, API вернул `502 AI_UNAVAILABLE` |
| H3, повтор только обычной подсказки | Три пункта на английском, до 150 слов, без готового текста |
| G3, только вопросы для защиты | Четыре вопроса и пояснения на английском, один вопрос по декларации ИИ |

Автоматические тесты проверяют передачу контекста, экранирование тегов, лимиты,
права, формат ответа, обработку ошибок и общий таймаут запроса.
