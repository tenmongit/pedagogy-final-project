# Izden — фронтенд

React + TypeScript + Vite, Tailwind CSS v4, shadcn/ui (Radix), TanStack Query, React Router.
Зона Ильяса. Контракт с бэкендом — только раздел 6 `CLAUDE.md`.

## Запуск

```bash
cd frontend
npm install
npm run dev        # http://localhost:5173
```

По умолчанию работает на **моках**: данные живут в браузере (`localStorage`), бэкенд не нужен.
Сид как в разделе 8 спеки: преподаватель, три студента, одно задание, у Данияра работа на финале.
Кнопка «Сбросить» внизу боковой панели возвращает сид.

Чтобы ходить в настоящий бэкенд, создайте `.env.local`:

```bash
VITE_USE_MOCKS=false
VITE_API_URL=http://localhost:8000
```

## Языки

Интерфейс на русском, казахском и английском (`src/i18n`). Переключатель RU / KZ / EN внизу боковой
панели и на экране входа; выбор запоминается в браузере, по умолчанию берётся язык браузера, иначе русский.

- `ru.ts` — эталон: его форма задаёт тип `Messages`. Если в `kk.ts` или `en.ts` не хватает ключа,
  проект не соберётся.
- В компонентах: `const t = useT()` → `t.assignments.title`, `t.work.versions(3)` (склонения внутри словаря).
- Даты и числа — через `useI18n()`: `formatDate`, `formatDateTime`, `formatNumber`.
- Сообщения ошибок сервера показываются как есть; бэкенд получает заголовок `Accept-Language`.
  Данные (тексты работ, подсказки в моках) не переводятся.
- Казахский перевод стоит проверить носителю языка перед демо.

## Цвет

Интерфейс монохромный, цвет только со смыслом:

- кобальт `primary` — действие и голос преподавателя;
- фиолетовый `ai` — любое использование ИИ;
- красный `destructive` — только ошибки ввода и сбои, никогда не про честность студента;
- зелёный `success` — «Оценено»;
- янтарный `defense` — «Ожидает защиты»;
- `DemoBadge` — пометка «Демо / в разработке» (раздел 8 спеки).

## Честность демо

Ответы «ИИ» в моках — заглушки, они подписаны в тексте. Пока ИИ-модуль Мерея не подключён,
блоки ИИ в интерфейсе помечаются `DemoBadge`. На моках плашка есть всегда, с настоящим бэкендом
её снимает только `VITE_AI_DEMO=false` — ставить, когда ИИ работает по-настоящему.
